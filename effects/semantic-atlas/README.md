# 语义动画库 V1.0.1

这是一个独立的动画探索工程，不属于“封面海报 V2”，也不接入当前生产剪辑 Skill。它的目标是探索动画语法、验证表现力、沉淀可复用素材。

## 版本

- V1.0.0：用户确认分类逻辑丰富后的首个冻结版本，位于 `../releases/semantic-motion-atlas-v1.0.0`。
- V1.0.1：修复阈值数字遮挡、动态文字提前露出、漫画分格布局三个问题。
- 分类体系不变，V1.0.1 只做缺陷修正。

## 当前能力

- 24 个可运行场景：16 个原子语法 + 8 个复合叙事。
- 每个场景可独立渲染为 1080×1920、30fps、6 秒的 H.264 MP4。
- 默认只播放一次，播放完自动停住。
- 支持暂停/继续、重播、进度拖动、0.5×/1×/1.5×和可选循环。
- 支持按原子/复合、家族、关键词筛选。
- 实验阶段允许 100% 动画，不设 25% 到 40% 占比规则。

## 打开实验室

在本目录启动静态服务器：

```bash
python3 -m http.server 5183 --bind 127.0.0.1
```

浏览器打开：

```text
http://127.0.0.1:5183/gallery.html
```

## 渲染

渲染一个场景：

```bash
npx hyperframes@0.6.64 render . \
  --variables '{"sceneId":"mask-reveal"}' \
  --strict-variables \
  --output renders/01-mask-reveal.mp4 \
  --fps 30 \
  --quality standard \
  --workers 1 \
  --strict-all
```

渲染并校验全部场景：

```bash
node render_all.mjs
```

## 目录

- `TAXONOMY.md`：分类边界、16 类原子语法、8 类复合叙事。
- `gallery.html`：交互式预览与控制台。
- `index.html`：单场景渲染入口。
- `renders/`：24 个独立动画成片和编码校验索引。
- `qc/`：三时态抽帧、桌面/手机截图与自动验收报告。
- `VERSION.json`：实验版本身份与生产隔离声明。

## 生产隔离

本目录不修改、不替代、不引用以下生产路线：

- “封面海报 V2”视频剪辑风格。
- `IP自动剪辑` Skill。
- `VibeMotion科普动画` Skill。

只有在完成独立选型、真人口播实测和用户明确确认后，某个动画才可以复制到新的生产版本中。旧版本始终保留。
